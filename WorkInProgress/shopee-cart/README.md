
# 📖 Objetivo

Código backend que simula um carrinho de compras proposto pelo desafio "Carrinho de Compras da Shopee com Node.js" da [Formação Node.js Fundemtanls](https://web.dio.me/track/formacao-nodejs-fundamentals)

O objetivo é recriar a lógica de um carrinho de compras, envolvendo armazenamento de itens e cálculo de sub-itens automaticamente.
O domínio da aplicação é o carrinho de compras e suas entidades representadas são cart.js (para representar o carrinho) e item.js (para representar os itens).

Além disso, o projeto também atua como comprovação do desenvolvedor apresentar suas capacidades de arquitetura como:
- Código Modularizado
- Código Organizado

O arquivo index.js é o controller. Os arquivos cart.js e item.js são os services.

_Houve correções em comparação ao projeto original do desafio, e provavelmente haverá adições no futuro se eu revisitar esse projeto._
